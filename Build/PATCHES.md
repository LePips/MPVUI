# Native patches

[Inputs.lock.json](Inputs.lock.json) pins source revisions, patch order, platform selection, and checksums. Apple and Android share mpv and FFmpeg revisions but apply different patch sets. The tables explain each change.

| [0005-avfoundation-native-video](Patches/mpv/0005-avfoundation-native-video.patch)                                                   | Apple          | Add AVFoundation video output with sample-buffer timing, seeking, and subtitle composition.                                        |
| [0006-avfoundation-compressed-audio](Patches/mpv/0006-avfoundation-compressed-audio.patch)                                           | Apple          | Add optional AC-3/E-AC-3 playback through AVPlayer with bounded buffering and route recovery.                                      |

| [0009-native-hdr-color-metadata](Patches/mpv/0009-native-hdr-color-metadata.patch)                                                   | Apple          | Preserve native HDR color metadata and apply HDR subtitle luminance.                                                               |

| [0017-track-switch-buffering](Patches/mpv/0017-track-switch-buffering.patch)                                                         | Apple          | Preserve buffered audio and video during track refresh seeks.                                                                      |
| [0018-simulator-frame-upload](Patches/mpv/0018-simulator-frame-upload.patch)                                                         | Apple          | Copy CPU frame uploads into Metal-owned buffers on Apple simulators.                                                               |
| [0006-mpv-dovi-yuv](Android/Patches/0006-mpv-dovi-yuv.patch)                                                                         | Android        | Connect decoded Dolby Vision frames to libplacebo through OpenGL ES.                                                               |
| [0008-mpv-gles-bitmap-subtitles](Android/Patches/0008-mpv-gles-bitmap-subtitles.patch)                                               | Android        | Support bitmap subtitle textures on OpenGL ES devices without native BGRA texture support.                                         |
| [0019-avfoundation-buffer-reuse-and-subtitle-compositing](Patches/mpv/0019-avfoundation-buffer-reuse-and-subtitle-compositing.patch) | Apple          | Reuse frame buffers and color metadata, and reduce work when composing native subtitles.                                           |
| [0020-unavailable-pixel-aspect-ratio](Patches/mpv/0020-unavailable-pixel-aspect-ratio.patch)                                         | Apple, Android | Omit unavailable pixel aspect ratios so invalid values don't trigger repeated state updates.                                       |
